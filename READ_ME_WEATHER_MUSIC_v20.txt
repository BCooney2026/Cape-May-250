COONEY WEATHER-DRIVEN MUSIC SETUP v20

This package uses simple mood filenames:

assets/audio/hot.mp3
assets/audio/rain.mp3
assets/audio/windy.mp3
assets/audio/perfect.mp3

Optional:
assets/audio/cloudy.mp3
assets/audio/storm.mp3
assets/audio/cold.mp3

The config file is:
assets/config/vacation-config.js

Edit that one file to change quips, song labels, or the exact filenames.

IMPORTANT:
This package does not include copyrighted songs. You upload your own MP3 files into assets/audio/ using the exact filenames above.
